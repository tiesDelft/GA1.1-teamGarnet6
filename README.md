
**multiply**
function for multiplying a and b. The function only works for integers and floats.
call using:
    multiply(a=4, b=10)
    
**subtract**
Use this function to subtract a from b. The function only allows integers and floats.

call using:
    subtract(a=5.0, b=2.1)
    

**add** 
this function contains the add function which is used to add two values together.  this function requires floats.

(add(3,2))

**distance from zero** 
use this function to find the absolute value from the subtraction. 

call using:
    distance_from_zero(a = 3, b=12)
**sum_list**
This function loops over the numbers given and returns the total. The function only accepts a list of integers or floats.
